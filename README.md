# Database_Design
Repository for CS590 - Database Design and Development as part of my masters in Computer Science at Southern New Hampshire University

**Author:** Jo Cooper

---

## Summary
This course covers database principles and implementation. This includes the advantages, disadvantages, and use cases of different database structures. Databases covered in this class include relational databases with PostgreSQL, graph databases with Neo4j, and document databases with MongoDB. All three database types are used in the creation of dashboards in Jupyter Labs. 

Database links go to folders with back ups of implemented databases. Module 3 and 6 include entity relationship diagrams and graph example for Neo4j. 

Dashboard folders include pngs of the created dashboard and an html of the Jupyter file.
